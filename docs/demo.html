场景 05 · 安全红线

接口级 Guards，越权一律 403

Network · /api/admin/users
GET/api/admin/users不带 Authorization
GET/api/admin/usersBearer <USER accessToken>
GET/api/admin/usersBearer <ADMIN accessToken>
401{ "code": 40100, "message": "未登录或 token 无效", "data": null }
403{ "code": 40300, "message": "权限不足", "data": null }
200{ "code": 0, "message": "ok", "data": { "items": [...], "total": 3 } }
⬡

JwtAuthGuard + RolesGuard 是安全边界；前端路由守卫只做体验分流。密码 bcrypt 哈希、JWT 短时 access + refresh 轮换、密钥不入库。
